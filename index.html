Evolving LLM KV Cache Quantization for On-Device Biomedical NLP

Stephane Morcos Douaihy · Pierre-Emmanuel Hladik · Mikael Briday · Zhaozhuo Xu

2026 Symposium LIEAF · Paper — Student · Session S51 · November 9, 2026 · 4:18–4:30 PM CT · Hilton Anatole, Dallas

Artificial IntelligenceLarge Language ModelsNatural Language Processing
Read abstract

Large Language Models (LLMs) enable powerful biomedical Natural Language Processing (NLP), but their key-value (KV) cache during autoregressive generation creates substantial memory and latency burdens on edge devices. We present an evolutionary approach to KV cache quantization that couples KIVI, an asymmetric 2-bit quantizer, with OpenEvolve, an LLM-driven evolutionary framework, to automatically evolve per-model and per-task hardware-aware quantization configurations balancing task quality, latency, and memory footprint. We evaluate LLaMA-2 (7B), LLaMA-3.1 (8B), Mistral-7B, and BioMistral-7B on four biomedical tasks (Cochrane-PLS, PLOS, MultiClinSum, MEDIQA-Task3). The top evolved KIVI configurations are validated on an NVIDIA Jetson Orin for a representative model (BioMistral-7B). Our evolutionary KV cache quantization achieves substantial memory reductions (≈ 80%) with minimal quality degradation (∆ROUGE-L ⪅ 5%). We report Pareto fronts, per-task tradeoffs, analyze global versus per-task tuning, and provide practical recommendations for deploying LLMs in on-device biomedical NLP applications.
